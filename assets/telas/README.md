O arquivo da HU06 contém as telas de atendimento, solicitações e cancelamento, além dos estados alternativos e do mapa de telas.

Abra os arquivos com o Live Server para carregar os dados JSON via `fetch`. As prévias disponíveis também permitem abertura direta. Os dados são fictícios.

Os HTMLs antigos de `pages/` redirecionam para esta pasta e preservam os parâmetros da URL e o fragmento. Eles não mantêm uma segunda implementação das telas.

O template compartilhado e seu guia ficam em [assets/templates/](../templates/README.md). As próximas telas do grupo devem ser criadas nesta pasta, usando caminhos como `../css/`, `../js/` e `../img/`.
