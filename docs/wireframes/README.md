## Leitura das imagens

Cada PNG corresponde a um quadro completo do Figma, inclusive quando a tela é alongada. Os arquivos de cada HU usam o prefixo correspondente, como `hu03-`. Os estados alternativos mantêm o prefixo da HU que representam.

Os rótulos do Figma identificam os responsáveis pelas HUs. A associação dos estados alternativos considera a área e o conteúdo da tela. As personas e dores vêm das histórias e jornadas do repositório.

Os dados são fictícios. As imagens não comprovam funcionamento do aplicativo ou melhoria dos indicadores. Cada documento de HU registra seus limites e os links dos quadros de origem.
